# OpenL3 research environment for the MusicPack Sonic benchmark.

# Pinned for reproducibility on macOS arm64 / Linux x86_64, CPython 3.11.
# (CPython 3.11 is required: openl3 0.4.0 is unmaintained and the Keras-2

# and downloads all model weights during build. Install the patched tree
# instead (see bootstrap_env.sh / patch_openl3.py):

#     uv pip install --python .venv/bin/python wheels/openl3-0.4.0
